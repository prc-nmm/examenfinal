# Script para evaluar de Examen Final Práctico - Sección 1
## DESCRIPCIÓN
Script para evaluar la Sección 1 del Examen Final Práctico del curso NMM de PRC.

## EVALUACIÓN
Se busca validar que el estudiante:
- Pueda instalar SNMP
- Pueda configurar correctamente SNMP
- Pueda clonar GIT

## ENTREGA
Debe subir al GES una impresión de pantalla del resultado final.
